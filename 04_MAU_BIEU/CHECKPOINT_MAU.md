# CHECKPOINT — mẫu thay bằng dữ liệu JOB cụ thể

- `JOB_ID`: DEMO-JOB-000
- `BOOK_ID`: DEMO-A-CASH-2026
- `PERIOD`: 2026-11
- `MODEL / EFFORT`: [nhập theo phiên thực tế]
- `WORKTREE / BRANCH / COMMIT`: [nếu có]
- `STATUS`: QUEUED / IN_PROGRESS / BLOCKED / REVIEW / DONE
- `SOURCE_SNAPSHOT_ID`: SYNTHETIC-DEMO-V1
- `FILES_READ`: [tên file + version]
- `FILES_CHANGED`: [nếu có]
- `COMMANDS_RUN + EXIT`: [log]
- `TESTS_RUN + RESULT`: [bằng chứng]
- `NEXT_SAFE_STEP`: [một câu]
- `NEEDS_OWNER_APPROVAL`: [không/có + lý do]
- `RISK/UNRESOLVED`: [liệt kê]

Không lưu mật khẩu, token, hình chứng từ riêng tư, số tài khoản vào checkpoint dùng chung.
